## ✨ Key Features (Kya kya kaam karta hai?)

*   📸 **Citizen Reports:** Log apni location ki waste (kachre) ki photo upload kar sakte hain.
*   🧠 **AI Triage (Simulation):** AI image ko analyze karke waste ka volume aur type batata hai (e.g., Plastic, Organic, Construction debris).
*   🚨 **Severity Scoring:** Har report ko ek priority score milta hai (High, Medium, Critical).
*   🗺️ **Live Hotspot Map:** Ek interactive India/City map jo dikhata hai kahan sabse zyada kachra jama hai.
*   📊 **Analytics Dashboard:** Field teams aur admins ke liye data insights aur graphs.

## 🛠️ How It Works?

1.  **Detect 📷 :** Citizen portal ke through issue report karte hain.
2.  **Analyze 🧠 :** AI model issue ko verify karta hai aur risk/priority assign karta hai.
3.  **Resolve 🚛 :** Municipal team ko location aur map data milta hai, jisse unki truck routing aasan ho jati hai.
